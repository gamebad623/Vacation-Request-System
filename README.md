# 🏢 Laravel Vacation Request Management REST API

A production-style **Employee Vacation Management Backend API** built with **Laravel, MySQL, Eloquent ORM, and Role-Based Middleware**.

This project simulates a real HR workflow with **employee and admin/manager roles**, including vacation request submission, approval workflows, status lifecycle management, and protected admin actions.

---

## 🚀 Features

### 👤 Employee
- Register / Login
- Submit vacation requests
- Update pending requests
- Cancel requests
- View personal request history
- Track request status

### 👑 Admin / Manager
- View all employee vacation requests
- Approve requests
- Reject requests
- Update request statuses
- Protected routes using custom admin middleware
