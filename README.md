🏢 Laravel Vacation Request Management API

A production-style Employee Vacation Management Backend API built with Laravel, MySQL, and RESTful API best practices.

This project simulates a real HR workflow where employees can submit vacation requests and managers/admins can review, approve, or reject them through a controlled status lifecycle.

🚀 Features
👤 Employee
Submit vacation requests
View personal request history
Update pending requests
Cancel requests
Track request status
👑 Manager / Admin
View all employee requests
Approve requests
Reject requests
Update request statuses
Protected routes with role-based middleware
